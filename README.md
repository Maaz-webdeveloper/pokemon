# ⚡ Pokémon Cards App

A responsive React web application built with **Vite** that fetches and displays detailed Pokémon data using the **PokeAPI**. Users can search for their favorite Pokémon in real-time.

---

## ✨ Features

- **Real-Time Search:** Instant filtering of Pokémon as you type.
- **Detailed Stats:** Displays Height, Weight, Speed, Experience, Attack, and Abilities for each Pokémon.
- **Fallback Image Handling:** Gracefully handles missing sprites using multiple fallback image URLs.
- **Async Data Fetching:** Efficiently loads multiple API requests concurrently using `Promise.all`.
- **Responsive Design:** Optimized layout using modern CSS Grid and Flexbox for Mobile, Tablet, and Desktop screens.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (JSX)
- **Build Tool / Bundler:** Vite
- **Package Manager / Runtime:** Bun / npm
- **Styling:** CSS3 (Custom CSS Grid, Flexbox, & Media Queries)
- **API:** [PokeAPI](https://pokeapi.co/)
